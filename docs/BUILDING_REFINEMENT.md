# Building instance refinement experiments

The validation-only study retains the selected flip baseline (50% fixed fusion, .35 threshold, adaptive seeds at 6 pixels), compares connected and watershed partitions, and measures conservative adjacency-based fragment merging. Hybrid views blend 65% flip and 35% multiscale probability while retaining flip-aligned auxiliary heads. The experiment never uses test rows or trains weights.

Run `python scripts/building_refinement_study.py --dataset DATASET --models PRIMARY SECONDARY --output REPORT.json --device cuda`. Reports include per-image overlap patterns, pixel/object/boundary scores, and validation-only temperature fits. The oracle-mask connected diagnostic is not a deployable algorithm or a theoretical upper bound. Fragment merging preserves all foreground and holes; it must be validated before deployment. No prior result is overwritten.

CUDA vision sessions and GPU acceptance profiling disable TF32 by default. The upstream mixed-precision DINO model is not automatically rewritten: use the independently hashed, locally converted FP32 derivative validated on the target host. Windows ONNX sessions now register the complete active environment NVIDIA wheel family and process-local DLL paths before preloading, with explicit toolkit override retained. Real Windows hardware must requalify this change.

The ablation also tests weak local probability valleys plus signed distance as supplementary ridge evidence, conservative one-pixel contour corrections, and combined repair. The contour candidate preserves enclosed holes when adding pixels but is not a general topology guarantee. Raw probabilities remain unchanged for Brier and temperature calibration. Leave-one-source-group-out NLL provides a cross-fitted within-validation check, not a new region holdout.
